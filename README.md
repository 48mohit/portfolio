# Personal Portfolio Website

A simple, responsive portfolio website that introduces me, my skills and my projects.

**Live site:** https://48mohit.github.io/portfolio/

## About

I built this project to practise HTML and CSS and to publish my first project on GitHub.

## Features

- Responsive layout that works on mobile and desktop
- Sections for About, Skills, Projects and Contact
- Smooth scrolling navigation
- Colors kept in CSS variables, so the theme is easy to change

## Built with

- HTML5
- CSS3 (Flexbox, media queries, CSS variables)
- Git and GitHub, hosted on GitHub Pages

## Run it locally

1. Download or clone this repository:
   `git clone https://github.com/48mohit/portfolio.git`
2. Open `index.html` in any browser.

## What I learned

- Structuring a page with semantic HTML tags
- Styling and layout with CSS
- Making a page responsive with media queries
- Using Git to commit and push code, and GitHub Pages to deploy
